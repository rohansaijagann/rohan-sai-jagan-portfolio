## ⚡ Highlights & Features

- **💻 Realistic VS Code IDE Experience**:
  - Functional Activity Bar with tab switching
  - Explorer Sidebar with expandable tree structure
  - Tab Bar with file icons and active indicators
  - Status Bar with git branch, error/warning badges, and quick toggles
- **🎨 6 Handcrafted IDE Themes**:
  - VS Code Dark+ (Default)
  - Monokai Pro
  - One Dark Pro
  - Dracula
  - GitHub Dark
  - Cyberpunk Neon
- **⌨️ Command Palette & Quick Navigation**:
  - Press `Ctrl + K` (or `Cmd + K`) to launch the command palette
  - Jump instantly between sections, change themes, or download resume
- **🧊 Interactive 3D Rubik's Cube**:
  - Rotatable and solvable 3D puzzle powered by interactive canvas mathematics
- **🎨 "Paint with Code" Interactive Canvas**:
  - Interactive background particles and drawing canvas
- **📄 Built-in PDF Resume Viewer**:
  - View resume inline within editor tabs or download directly
- **📱 Responsive & Accessible**:
  - Meticulously tested across mobile (390px), tablet (768px/1024px), and desktop (1440px+)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or newer recommended)
- npm or bun

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/rohansaijagann/rohan-sai-jagan-portfolio.git
   cd rohan-sai-jagan-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Open your browser at `http://localhost:3000` (or the port indicated in your terminal).

---

## 📦 Building for Production

```bash
npm run build
```
The output files will be in the `dist/` folder ready for deployment on Vercel, Netlify, or GitHub Pages.
